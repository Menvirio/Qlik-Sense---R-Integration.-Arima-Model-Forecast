Predictive analysis with Arima model written in R code and embedded in Qlik editor script



1. Introduction
Hello everyone! I was asked to implement a predictive model in Qlik Sense for a work project.
The model had been originally written in R code and the project was about transferring it on Qlik Sense, so that the forecast could be automatically scheduled every month. 
Doing so, the client could watch the predicted results on the dashboard and export data in excel  with no manual intervention. 
In this document I would like to show how to apply the Arima predictive model on a simple time series dataset, in order to predict the outcome of a target variable for the following months. 
I think the added value of this document can be found in chapter 5, where it is explained line-by-line how to recall the R script in the Qlik Sense editor. So if you had already installed R-Serve and the SSE-R plug I recommend you to  directly go to this chapter. 


2. Dataset
As mentioned in the introduction, the dataset is very simple and it is composed of two columns: 
* Time Dimension. It represents the period of time in which the target dimension is observed. Granularity can be different according to the time span (Year, month, day, hour…); however, it does not affect the forecast model. 
* Target Dimension. It is the numeric variable that we want to predict. It could be literally anything: Revenues, #Orders, #Customer Tickets , #Rain drops in a certain region etc. 
In our case, the dataset  dimensions are the number of months from Jan. 2018 to Dec 2021 and we will pretend that the target variable is the number of orders that a fictional company has received during the last 48 months.

4. Advanced analytics integration
Before moving to the Qlik Sense editor script, it is necessary to install a R Serve and SSE R plugin to perform predictive analytics in Qlik Sense. 


Advanced analytics integration in Qlik Sense and QlikView allows users to interact with and explore advanced calculations from third-party engines such as R, Python, Matlab, Spark, etc. As users make selections, data is sent from the Qlik engine to third party tools, calculations are made in realtime, and the results are returned and immediately visualized for the user. This allows people to ask their own questions and spot insights that would have been missed with query-based or batch approaches. 
  


In our case we need to install: 


* Rserve — A TCP/IP server which allows other programs to use R without initialising a separate R process or linking against an R library; and
* SSE R-plugin — A server-side extension (SSE) which provides the interface between Qlik Sense and Rserve.
You may find detailed instruction on how to install these two components by clicking on the  following link:
